## Что изменено
- HTML-шаблоны вынесены из `app.py` в `templates_ui.py`.
- Расчёт износа и текстовая интерпретация вынесены в `wear.py`.
- На странице карточки оборудования отображается процент износа, маркировка уровня (низкий / умеренный / высокий / критический), пояснение и шкала прогресса.
- Визуальный стиль обновлён в сторону минималистичного каршерингового интерфейса: тёмная навигация, зелёный акцент, спокойные карточки, меньше декоративных элементов и эмодзи.

## Важно про износ
Износ рассчитывается ориентировочно по дате приобретения и нормативному сроку службы. Он не является результатом автоматического распознавания повреждений или технической экспертизы. В карточке это явно указано.

## Запуск
В окружении, где установлены зависимости проекта:

```bash
python app.py
```

По умолчанию приложение доступно на `http://127.0.0.1:5000`. Если в исходном проекте есть `requirements.txt`, сначала установите зависимости командой `pip install -r requirements.txt`.


## Последние изменения
- Убраны пункты «Журнал действий» и «Резервные копии» из административного интерфейса, а также маршруты и автоматический поток резервного копирования.
- При оформлении возврата можно прикрепить до 6 фотографий в форматах JPG, PNG или WEBP. Фотографии сохраняются локально в `uploads/returns/`, а их список связывается с записью возврата в базе данных.
- В списке возвращённого имущества доступна ссылка для просмотра фотографий возврата.
- Для существующей базы данных поле `return_photos` добавляется автоматически при запуске.
